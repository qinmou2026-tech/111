# 经济数据分析入门

用一个小项目练习微观经济学、宏观经济学、概率统计和 Python 数据分析。先跑通“读取数据 → 计算指标 → 理解结果”，再逐步加入真实收入、消费和 CPI 数据。

## 快速开始

需要 Python 3.10 或以上版本；当前示例只使用标准库，无需安装第三方依赖。

下载或克隆本仓库后，在仓库根目录运行：

```bash
python src/analyze.py
```

Windows 若使用 Python 启动器，也可运行 `py src/analyze.py`。

预期输出：

```text
模拟数据：3 期（2025-01 至 2025-03）
平均名义收入：5200.00 元/月
平均消费：3200.00 元/月
各期消费占收入比例的平均值：61.50%
平均实际收入（基期价格）：5147.54 元/月
```

数据是人为构造的教学样例，不代表任何地区或居民的真实状况。

## 示例数据与指标

每行代表一个月的模拟居民收入、消费和价格指数；金额采用同一口径，均为元/月。

| 字段 | 含义 |
| --- | --- |
| month | 月份，格式 YYYY-MM |
| income | 名义收入，元/月 |
| consumption | 消费支出，元/月 |
| cpi | 同一固定基期的价格指数，基期 = 100 |

- 消费占收入比例 = 消费支出 ÷ 名义收入。示例报告的是各月比例的算术平均。
- 实际收入 = 名义收入 ÷ (CPI ÷ 100)，表示按基期价格衡量的购买力。
- CPI 在这里是**固定基期指数**，不能直接换成“上年同月 = 100”的同比指数。
- 这些描述性指标不能单独证明收入与消费之间的因果关系。

## 逐步扩展

1. **Python 与统计**：修改样例数值，练习均值、中位数、标准差，再尝试 pandas 读取 CSV。
2. **微观经济学**：比较各月消费占比与储蓄（收入减消费），观察收入变化时的消费变化。
3. **宏观经济学**：加入更多月份，画出名义收入、实际收入和 CPI 趋势。
4. **真实数据**：引入收入、消费和 CPI 数据，记录来源、单位、时间频率、地区和基期；先统一口径，再分析。

暂时不需要数据库、网络接口或复杂模型。先理解每个字段和计算结果。
